本文档描述如何对比多个 perfeye 任务的性能数据，识别性能回归和改进。

> **⭐⭐⭐ 重要：AI Agent 生成性能对比分析报告时，必须在报告最后附带 perfeye 网站的对比链接！**
>
> **链接格式**：`https://perfeye.console.testplus.cn/compare/{uuid1},{uuid2},{uuid3}`
>
> 这是用户查看详细对比数据的重要入口，**不可省略**！

## 对比工作流程

```
Step 1: 获取多个任务的性能数据
    ↓
Step 2: 提交数据给 AI Agent
    ↓
Step 3: AI Agent 生成性能对比分析报告
```

## Step 1: 获取多个任务的性能数据

使用 `cli.py` 获取每个任务的性能指标：

```bash
# 获取任务 1 的数据
python scripts/perfeye_cli.py --uuid <uuid1> --metrics -o task1.json

# 获取任务 2 的数据
python scripts/perfeye_cli.py --uuid <uuid2> --metrics -o task2.json

# 获取任务 3 的数据
python scripts/perfeye_cli.py --uuid <uuid3> --metrics -o task3.json
```

**或者** 获取完整数据（包含 LabelInfo.All）：

```bash
python scripts/perfeye_cli.py --uuid <uuid> --full -o task_full.json
```

## Step 2: 提交数据给 AI Agent

将获取的 JSON 数据提交给 AI Agent：

**方式 1：直接提供 JSON 文件**
```
"对比 task1.json、task2.json、task3.json 的性能数据，生成对比报告"
```

**方式 2：粘贴 JSON 内容**
```
"分析以下三个任务的性能数据，生成对比报告：

任务1: { ... }
任务2: { ... }
任务3: { ... }"
```

**方式 3：提供 UUID 列表**
```
"对比 UUID1、UUID2、UUID3 的性能数据，生成对比报告"
```

## Step 3: AI Agent 生成性能对比分析报告

AI Agent 将根据本指南的要求，生成包含以下内容的对比报告。

> **⭐ 关键要求：必须在报告最后附带 perfeye 网站对比链接！**
>
> **格式**：`https://perfeye.console.testplus.cn/compare/{uuid1},{uuid2},{uuid3}`
>
> 这是用户查看详细对比数据的重要入口，是报告中**不可或缺**的部分！

#### 环境一致性检查

**重要提示**：在进行性能对比之前，必须确保对比任务的测试环境一致，否则对比结果可能无效。

**检查项**：
- ✅ **CPU/GPU 一致**：不同硬件性能基线不同
- ✅ **分辨率一致**：2K vs 1080p 渲染负载差异 78%
- ✅ **画质一致**：High vs Medium 性能差异显著
- ✅ **案例名一致**：不同测试场景无法直接对比
- ⚠️ **版本可能不同**：版本对比是性能回归检测的主要目的

**环境不一致的处理**：
- 如果分辨率/画质不同，需要在分析时说明其影响
- 如果案例名不同，需要分别分析各场景的性能
- 如果硬件不同，需要说明性能预期差异

### 6. 综合评估

综合所有指标，给出总体评估和建议。

#### 评估维度

1. **性能趋势**：整体性能是提升还是下降
2. **回归检测**：是否存在性能回归
3. **达标情况**：是否达到 PC 平台基准
4. **稳定性**：FPS 波动、JANK 分布等
5. **资源健康**：CPU、GPU、内存是否健康

#### 综合评估示例

- uuid1 → uuid3 存在性能回归（FPS 下降、JANK 上升）

- 所有任务均达到 PC 平台基准
- 但 JANK 指标普遍偏高（15-22 次/10min）

### 7. perfeye 网站对比链接 ⭐（必需）
