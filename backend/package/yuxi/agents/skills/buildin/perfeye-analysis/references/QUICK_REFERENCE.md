# 性能指标快速参考

**用途**: AI Agent 进行性能分析时的快速查询表

## PC 平台达标标准

| 指标 | 达标 | 优秀 | 说明 |
|------|------|------|------|
| **AvgFPS** | ≥60 | ≥90 | 平均帧率 |
| **TP90** | ≥60 | ≥90 | 90分位帧率 |
| **Jank(/10min)** | <10 | <5 | 卡顿次数 |
| **BigJank(/10min)** | <5 | <2 | 严重卡顿 |
| **AvgCPU%** | <80% | <60% | CPU使用率 |
| **Avg(GPULoad)%** | <95% | <90% | GPU使用率 |
| **PeakMemory(MB)** | <10000 | <8000 | 峰值内存 |

## 画质级别识别

| 关键词 | 级别 |
|--------|------|
| Ultra, Very High, 极高 | 极高 |
| High, 高 | 高 |
| Medium, 中 | 中 |
| Low, 低 | 低 |
| Very Low, 极低 | 极低 |

## DrawCall 和面数标准（按画质）

| 画质 | DrawCall 达标 | 面数达标 |
|------|---------------|----------|
| 极高 | < 5000 | < 1000万 |
| 高 | < 4000 | < 700万 |
| 中 | < 2500 | < 400万 |
| 低 | < 1600 | < 200万 |
| 极低 | < 1000 | < 120万 |

## 常见问题诊断

| 症状 | 可能原因 |
|------|----------|
| AvgFPS < 60 | GPU不足、渲染过重 |
| TP90 << AvgFPS | 帧率不稳定 |
| Jank > 20 | 资源加载阻塞、GC频繁 |
| DrawCall > 3000 | 需要批处理 |
| GPU > 95% | GPU饱和 |
| MaxCTemp > 85°C | 散热不良 |
