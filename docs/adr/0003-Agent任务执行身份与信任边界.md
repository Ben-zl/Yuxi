# 0003 - Agent 任务执行身份与信任边界

Agent 任务保存在 Yuxi 并支持个人或部门可见；手动和 API 触发使用触发者作为执行身份，定时触发使用任务所有者。任务选择的工具审批模式直接适用于全部执行身份，默认“完全信任”，部门成员执行共享任务时不再增加逐成员授权；这保留了无人值守执行的简单语义，同时接受共享任务提示词可在触发者权限内执行敏感操作的风险。工具审批模式在 TaskExecution 触发时固定，后续修改只影响新执行；只有该次执行身份可批准或拒绝工具调用，任务创建者可取消但不能代替其他执行身份审批。执行历史不单独保存可见范围，始终跟随所属任务的当前可见范围；共享成员通过任务执行专用读取边界查看消息、事件和产物，不放宽普通线程和 AgentRun 的用户隔离。任务可见范围不得超过所引用智能体的可见范围，实际派发仍保留 AgentRun 主链路已有的智能体权限校验。
