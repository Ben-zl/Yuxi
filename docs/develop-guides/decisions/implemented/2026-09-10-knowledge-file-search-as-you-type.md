# 知识库文件搜索输入后自动查询

状态：implemented
类型：bug-fix
Owner：web/src/components/modals/FileSearchModal.vue

## 问题

知识库文件搜索弹窗的输入框只监听回车键。用户输入完整关键词后页面仍停留在提示状态，必须额外按回车才发送搜索请求，与搜索弹窗的即时反馈预期不符。

## 决策

监听搜索关键词变化，在停止输入 300ms 后自动调用现有文件名搜索接口。关键词变化时立即废弃正在返回的旧请求，避免旧关键词结果覆盖新关键词；清空输入时恢复初始提示；关闭弹窗时取消待执行定时器和在途结果提交。回车继续保留，并取消防抖等待后立即搜索。

## 替代方案

- 每个字符变化都立即请求：输入中文或较长关键词时会制造过多请求。
- 增加显式搜索按钮：仍要求额外操作，没有解决输入后自动反馈。
- 只修改提示文案要求按回车：保留了当前不必要的交互步骤。

## 后果

用户停止输入约 300ms 后会看到搜索结果，无需再按回车；回车仍可立即触发。连续输入会取消上一次定时任务并拒绝旧请求结果，清空或关闭弹窗会恢复初始状态。

## 风险

自动搜索会增加接口调用频率。300ms 防抖、请求 token 和关闭清理共同限制请求数量及迟到结果；后端搜索仍保留现有 100 条上限。
