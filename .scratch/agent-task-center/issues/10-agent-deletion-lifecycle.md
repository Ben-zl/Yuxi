# 10 — 约束被任务引用的智能体删除行为

**What to build:** 智能体删除不会留下仍可触发但永久失效的 AgentTask；允许删除时，归档任务和历史执行仍保留足够的智能体显示信息供审计。

**Blocked by:** 02 — 建立个人 AgentTask 定义管理

**Status:** done

**Source:** [父规格 #958](https://github.com/xerrors/Yuxi/issues/958)

- [ ] 任何未归档 AgentTask 引用智能体时，删除操作被明确阻止并返回可行动的错误信息。
- [ ] 所有关联任务归档后允许删除智能体，不自动迁移或重绑定任务。
- [ ] 任务及执行记录保存的智能体名称和 slug 展示快照在删除后仍可读取。
- [ ] 删除后的归档任务不可触发，历史详情不因智能体记录缺失而报错。
- [ ] 集成测试覆盖个人任务和部门共享任务对删除行为的约束。
