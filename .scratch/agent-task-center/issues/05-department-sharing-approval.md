# 05 — 支持部门共享、执行身份和工具审批

**What to build:** 任务可在个人和单部门范围间选择；部门成员可查看和触发共享任务，同时工具权限、审批和取消始终绑定明确的执行身份，不放宽普通线程的访问边界。

**Blocked by:** 04 — 实现任务级 FIFO 队列与生命周期操作

**Status:** done

**Source:** [父规格 #958](https://github.com/xerrors/Yuxi/issues/958)；执行身份与信任边界见项目 ADR 0003。

- [ ] 创建者可将任务设为自己所属的单个部门共享，范围仍不得超过智能体范围。
- [ ] 部门成员可查看、手动触发共享任务，手动执行使用触发者作为执行身份。
- [ ] “完全信任”直接适用于部门成员的执行身份，不增加逐成员二次授权。
- [ ] “请求审批”的执行只有该次执行身份能批准或拒绝；其他查看者看不到可用审批操作。
- [ ] 创建者可取消任务的任意执行，部门成员只能取消自己触发的执行，创建者不能代替他人审批。
- [ ] 共享成员通过任务执行专用只读入口查看消息、事件和产物；普通 Thread、AgentRun、SSE 和产物接口仍保持所有者隔离。
- [ ] 修改任务当前可见范围后，历史执行访问随当前范围变化，不维护历史范围快照。
